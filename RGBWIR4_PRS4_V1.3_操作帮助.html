支持四路TCS3400环境光参数设置与通道读取，以及RS485压力读取、清零、上下限判断和Y1～Y4输出控制。

积分时间的作用

积分时间决定传感器持续收集光信号的时间。时间越长，弱光下读数通常越大，但响应更慢，也更容易达到65535饱和。

  • 强光、近距离：优先缩短积分时间。
  • 弱光、隔着外壳：可以逐档增加积分时间。
  • 数据接近65535：应缩短积分时间或降低增益。

增益的作用

增益用于放大光信号。提高增益通常能让弱光读数更明显，但同时会放大噪声，并增加饱和风险。

  • 默认从4x开始。
  • 偏暗时先提高到16x。
  • 64x只用于极弱光，使用时重点观察噪声和饱和。

积分与增益计算器

压力传感器测试

压力仪表通过RS485访问。工作值2在读取和清零时表示实际Modbus地址，在设置限值时表示整数压力限值。

Modbus地址范围 001～247
上下限范围 000～999
通信参数 115200 / 8N1
测试前先确认：仪表供电、RS485 A/B线、115200 / 8N1通信参数和实际Modbus地址。
1

普通读取与清零

  • 普通读取

    Pin1 50，工作值2填写地址001～247。读取实际压力，不比较上下限，也不改变Y输出。

  • 按需清零

    Pin1 51，工作值2填写地址001～247。成功返回0.0，不改变限值和Y输出。

2

上下限与比较读取

  • ① 设置下限

    第1～4组使用Pin1 60 / 70 / 80 / 90，工作值2填写整数限值000～999。

  • ② 设置上限

    第1～4组使用Pin1 61 / 71 / 81 / 91，工作值2填写整数限值000～999，且上限必须大于下限。

  • ③ 比较读取

    第1～4组使用Pin1 62 / 72 / 82 / 92，工作值2填写地址001～247；读取成功后更新Y1～Y4。

压力值换算

主板先读取有符号原始压力，再读取仪表小数位。小数位允许0～4，最终结果按原始值除以10的对应次方计算。

例如原始值为 -1234，小数位为 2，返回压力为 -12.34，单位沿用仪表当前显示单位。

上下限判断

比较时使用压力绝对值，因此正压力和负压力按相同大小判断；返回给调试软件的压力仍保留原始正负号。

小于下限或大于上限才触发。等于下限或上限时不触发。

异常报错与排查

当前版本所有异常统一返回 -1.0，不区分具体错误编号。看到-1.0时按下面顺序排查。

统一异常值：-1.0。一次操作只返回一次结果；上一操作尚未完成时继续提交，也可能得到异常。

先查填写内容

  • Pin1是否是表中已经定义的操作。
  • Pin2是否正好为两位数字。
  • 工作值2是否为三位合法参数。
  • 读取颜色、IR或ID时是否填写000。
  • 积分、增益、地址和限值是否越界。

再查连接和时序

  • 等待上一操作返回后再提交下一项。
  • 检查TCS3400供电和对应SCL/SDA。
  • 检查压力仪表供电、A/B线和地址。
  • 确认压力仪表为115200bps、8N1。
  • TCS3400每条读取命令只采样一次，失败时不会自动重发。
  • IR读取会等待普通Clear恢复完成后再返回结果。
  • 压力响应超时为200ms，不自动重试。

恢复方式

  • TCS3400重新接好后，再次操作会自动尝试初始化。
  • 积分或增益设置失败时，主板会尝试恢复旧值。
  • 压力通信失败后检查连接，再手动重新操作。
  • 比较读取失败时，对应Y保持原状态。
  • 非法上下限不会覆盖已经保存的旧限值。
