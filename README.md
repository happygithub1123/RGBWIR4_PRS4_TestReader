# RGBWIR4_PRS4_TestReader

STC8H8K64U 四路 TCS3400 环境光与四路 RS485 压力仪表测试固件。

## 当前版本

**V1.3，合并于 2026-07-25。**

V1.3 已完成四路 TCS3400 实机读取验证，并在 V1.2 基础上完成四路压力上下限比较与 Y1~Y4 输出控制联调验证。当前 `main` 已包含 V1.3 功能：普通压力读取、压力清零、四组上下限设置、按实测压力绝对值比较，以及 Y1~Y4 独立输出控制。

V1.3 当前优化已于 2026-07-30 完成实机回归，并通过 PR #6 合并：保留已经跑通的传感器状态机，TCS3400 普通读取只访问 Pin1 指定通道并连续读取低、高两个字节；压力 Modbus 保持一问一答，每个子事务只发送一次并等待 200 ms。

## 主要功能

- 四路 TCS3400 共用一套驱动，通过四组独立 GPIO 软件 I2C 访问。
- 支持读取 R、G、B、Clear、IR 和芯片 ID。
- R、G、B、Clear 每条命令只读取目标通道，并从偶数低字节寄存器开始连续读取低、高两个字节。
- 支持六档积分时间：2.78、27.8、51、103、178、712 ms。
- 支持四档增益：1x、4x、16x、64x。
- 四路配置相互独立，上电默认 27.8 ms、4x。
- UART1 接收固定 15 字节 MTF 请求，返回 7 字节小端 Float 帧。
- UART2 + SN65HVD72 实现 Modbus RTU 压力读取和清零。
- 每个压力 Modbus 子事务只发送一次，响应超时为 200 ms，失败后由调试人员检查并重新操作。
- 四组压力上下限分别控制 Y1~Y4，支持只设下限、只设上限或同时设置。
- UART 中断只收发字节，业务通过主循环中的小型非阻塞状态机执行。
- 统一异常值为 Float `-1.0f`。

## 硬件参数

| 项目 | 参数 |
|---|---|
| MCU | STC8H8K64U-45I-LQFP48 |
| 系统时钟 | 22.1184 MHz 外部晶振 |
| UART1 | P3.0 RXD、P3.1 TXD，115200、8N1 |
| UART2 | P1.0 RXD2、P1.1 TXD2，115200、8N1 |
| RS485 方向 | P0.7，高电平发送、低电平接收 |
| 压力输出 | Y1=P3.2、Y2=P3.3、Y3=P3.4、Y4=P5.0 |
| TCS3400 地址 | 7-bit `0x39` |

SN65HVD72 的 2 脚 `/RE` 与 3 脚 `DE` 并接并通过上拉电阻连接 P0.7，1 脚 `R` 和 4 脚 `D` 分别带上拉。固件初始化后默认进入接收状态。

## MTF 协议

请求严格固定为 15 字节：

```text
MTF:AB-CD-EFG\r\n
012345678901234
```

- `AB`：两位十进制指令码。
- `CD`：两位十进制保留码，只校验数字，不解析、不保存。
- `EFG`：三位十进制参数，含义由 `AB` 决定。
- `\r\n`：必须发送真实字节 `0D 0A`。

### TCS3400 命令

`AB` 十位表示传感器编号 `1~4`，个位表示操作：

| 个位 | 功能 | EFG |
|---:|---|---|
| 0 | 设置积分时间 | `003/028/051/103/178/712` |
| 1 | 读取 R | `000` |
| 2 | 读取 G | `000` |
| 3 | 读取 B | `000` |
| 4 | 读取 Clear | `000` |
| 5 | 读取 IR | `000` |
| 6 | 设置增益 | `001/004/016/064` |
| 7 | 保留，返回异常 | 不适用 |
| 8 | 保留，返回异常 | 不适用 |
| 9 | 读取 ID | `000` |

推荐从默认档开始，根据亮度逐级调整：

| 档位 | 积分时间 | 增益 | 用途 |
|---|---:|---:|---|
| 高速强光档 | 2.78 ms | 1x | 高亮 LED、距离很近、快速扫描 |
| 强光档 | 27.8 ms | 1x | 较亮 LED，降低饱和风险 |
| 默认档 | 27.8 ms | 4x | 普通 RGBW LED |
| 弱光档 | 27.8 ms | 16x | 较暗 LED、隔着外壳 |
| 平衡灵敏档 | 标称 51 ms | 16x | 中弱光，兼顾速度和灵敏度 |
| 高灵敏档 | 103 ms | 16x | 弱光、反射检测 |
| 超高灵敏档 | 178 ms | 16x | 非常弱的 LED |
| 极暗档 | 712 ms | 16x，必要时 64x | 极暗或远距离检测，响应慢且需注意饱和 |

示例：

```text
MTF:10-00-028\r\n    第1路设置27.8 ms
MTF:16-00-004\r\n    第1路设置4x
MTF:11-00-000\r\n    读取第1路R
MTF:15-00-000\r\n    读取第1路IR
MTF:29-00-000\r\n    读取第2路ID
```

### 压力仪表命令

| AB | 功能 | EFG |
|---:|---|---|
| 50 | 普通读取压力，不比较、不改变Y | Modbus地址 `001~247` |
| 51 | 清零仪表，不改变限值和Y | Modbus地址 `001~247` |
| 60/70/80/90 | 设置第1/2/3/4组下限 | 整数限值 `000~999` |
| 61/71/81/91 | 设置第1/2/3/4组上限 | 整数限值 `000~999` |
| 62/72/82/92 | 读取压力、比较并控制Y1/Y2/Y3/Y4 | Modbus地址 `001~247` |

```text
MTF:50-00-001\r\n    读取地址1压力
MTF:51-00-001\r\n    清零地址1仪表
MTF:60-00-100\r\n    设置第1组下限100
MTF:61-00-200\r\n    设置第1组上限200
MTF:62-00-003\r\n    读取地址3，比较后控制Y1
```

设置上下限时返回设置值 Float；读取并比较时仍返回带正负号的实际压力 Float。限值判断使用实际压力的绝对值：`|压力|` 低于下限或高于上限时，ULN2003 将对应 Y 输出拉低；等于限值不触发。四组限值只保存在 RAM，重新上电后全部清除。

## 返回帧

正常返回固定 7 字节：

```text
3D B0 B1 B2 B3 0D 0A
```

`B0~B3` 是小端 IEEE754 Float。统一异常帧为 `-1.0f`：

```text
3D 00 00 80 BF 0D 0A
```

## 工程结构

```text
程序/TCS3400 LZ808-H Project/
├─ User       程序入口与主循环
├─ App        UART1组帧、MTF解析与回复
├─ Control    TCS3400和压力业务控制
├─ Hardware   软件I2C、TCS3400、Modbus和板级功能
├─ System     GPIO、UART、Timer、RS485与延时
├─ Public     公共配置和协议常量
└─ Project.uvproj
```

模块调用方向：

```text
User -> App -> Control -> Hardware -> System
```
