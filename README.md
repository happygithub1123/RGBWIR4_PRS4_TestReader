# RGBWIR4_PRS4_TestReader

STC8H8K64U 四路 TCS3400 环境光与四路 RS485 压力仪表测试固件。

## 当前版本

**V1.2，发布于 2026-07-18。**

V1.2 已完成四路 TCS3400 实机读取验证：四路独立软件 I2C 均可访问对应传感器，并已验证 ID 以及 R、G、B、Clear、IR 读取链路。压力仪表读取和清零代码已经实现，仍需连接 LZ808-H 实物完成最终联调。

## 主要功能

- 四路 TCS3400 共用一套驱动，通过四组独立 GPIO 软件 I2C 访问。
- 支持读取 R、G、B、Clear、IR 和芯片 ID。
- 支持五档积分时间：2.78、27.8、103、178、712 ms。
- 支持四档增益：1x、4x、16x、64x。
- 四路配置相互独立，上电默认 178 ms、16x。
- UART1 接收固定 15 字节 MTF 请求，返回 7 字节小端 Float 帧。
- UART2 + SN65HVD72 实现 Modbus RTU 压力读取和清零。
- UART 中断只收发字节，业务通过主循环中的小型非阻塞状态机执行。
- 统一异常值为 Float `-1.0f`。

## 硬件参数

| 项目 | 参数 |
|---|---|
| MCU | STC8H8K64U-45I-LQFP48 |
| 系统时钟 | 22.1184 MHz 外部晶振 |
| UART1 | P3.0 RXD、P3.1 TXD，115200、8N1 |
| UART2 | P1.0 RXD2、P1.1 TXD2，115200、8N1 |
| RS485 方向 | P0.7，高电平发送、低电平接收 |
| TCS3400 地址 | 7-bit `0x39` |

SN65HVD72 的 2 脚 `/RE` 与 3 脚 `DE` 并接并通过上拉电阻连接 P0.7，1 脚 `R` 和 4 脚 `D` 分别带上拉。固件初始化后默认进入接收状态。

## MTF 协议

请求严格固定为 15 字节：

```text
MTF:AB-CD-EFG\r\n
012345678901234
```

- `AB`：两位十进制命令码。
- `CD`：两位十进制占位符，只校验数字，不解析、不保存。
- `EFG`：三位十进制参数，含义由 `AB` 决定。
- `\r\n`：必须发送真实字节 `0D 0A`。

### TCS3400 命令

`AB` 十位表示传感器编号 `1~4`，个位表示操作：

| 个位 | 功能 | EFG |
|---:|---|---|
| 0 | 设置积分时间 | `003/028/103/178/712` |
| 1 | 读取 R | `000` |
| 2 | 读取 G | `000` |
| 3 | 读取 B | `000` |
| 4 | 读取 Clear | `000` |
| 5 | 读取 IR | `000` |
| 6 | 设置增益 | `001/004/016/064` |
| 7 | 保留，返回异常 | 不适用 |
| 8 | 保留，返回异常 | 不适用 |
| 9 | 读取 ID | `000` |

示例：

```text
MTF:10-00-178\r\n    第1路设置178 ms
MTF:16-00-016\r\n    第1路设置16x
MTF:11-00-000\r\n    读取第1路R
MTF:15-00-000\r\n    读取第1路IR
MTF:29-00-000\r\n    读取第2路ID
```

### 压力仪表命令

| AB | 功能 | EFG |
|---:|---|---|
| 50 | 读取指定 Modbus 地址的压力 | `001~247` |
| 51 | 清零指定 Modbus 地址的仪表 | `001~247` |

```text
MTF:50-00-001\r\n    读取地址1压力
MTF:51-00-001\r\n    清零地址1仪表
```

## 返回帧

正常返回固定 7 字节：

```text
3D B0 B1 B2 B3 0D 0A
```

`B0~B3` 是小端 IEEE754 Float。统一异常帧为 `-1.0f`：

```text
3D 00 00 80 BF 0D 0A
```

## 工程结构

```text
程序/TCS3400 LZ808-H Project/
├─ User       程序入口与主循环
├─ App        UART1组帧、MTF解析与回复
├─ Control    TCS3400和压力业务控制
├─ Hardware   软件I2C、TCS3400、Modbus和板级功能
├─ System     GPIO、UART、Timer、RS485与延时
├─ Public     公共配置和协议常量
└─ Project.uvproj
```

模块调用方向：

```text
User -> App -> Control -> Hardware -> System
```

## 编译

1. 使用 Keil C51 打开 `程序/TCS3400 LZ808-H Project/Project.uvproj`。
2. 选择 `Target 1` 并执行 Rebuild。
3. 当前 V1.2 构建结果为 `0 Error(s), 0 Warning(s)`。

Keil 的 `Objects/`、`Listings/`、HEX 和本机 `uvgui` 文件不提交到源码仓库。V1.2 的 HEX 固件作为 GitHub Release 附件提供。
